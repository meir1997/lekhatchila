# לכתחילה — תנועה לחרדיות ממלכתית

אתר רשמי של תנועת לכתחילה.

## פיתוח מקומי

האתר סטטי לחלוטין (HTML/CSS/JS). פתיחה מקומית:

```bash
# פתיחה ישירה בדפדפן
start index.html

# או שרת מקומי פשוט
python -m http.server 8000
```

## אירוח

האתר מתארח ב-GitHub Pages. הענף `main` מתפרסם אוטומטית.
דומיין סופי: `lekhatchila.co.il` (מנוהל ב-box.co.il).

## מבנה

- `index.html` — עמוד יחיד עם כל הסעיפים
- `styles.css` — עיצוב, RTL, responsive
- `script.js` — תפריט נייד, גלילה חלקה, טופס הצטרפות
- `CNAME` — מיפוי הדומיין הראשי (יתווסף בעת חיבור הדומיין)
